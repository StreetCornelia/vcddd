## Coding 事件处理

本节只在当前工作属于 Coding 时保留。

- 本系统前置任务全部集成且系统外依赖可用：在 `Coding 状态.md` 标记为 `ready`，启动或恢复该任务的开发 Agent。
- 开发 Agent 形成候选 Commit：登记候选并加入串行集成队列，开发 Agent 停止修改。
- 集成分支空闲且队列非空：把队首候选交给独立集成 Agent。
- 候选被退回：恢复原开发 Agent；新候选形成后加入队尾。
- 候选集成成功：登记新集成 Commit，移出队列，立即检查直接后继任务。
- 开发或验证缺少用户控制的运行条件：立即向用户索取，登记受影响动作和仍可继续的工作，不记录敏感值。
