# Pre-Coding 能力边界

**阅读身份：** VCDDD 主控 Agent。本文只允许识别能力边界和协议实现状态，不授权你开展本能力的专业工作。

## 已确定边界

Pre-Coding 把当前业务与 Domain 事实形成面向 Coding 的切面投影，推荐产出包括：

- 架构设计；
- 模块拆分；
- API 设计；
- 逐 API 核心接口内部编排；
- 数据库设计；
- 开发基线。

这些文档不能反向成为业务或 Domain 的权威来源。发现业务、所有权、Domain 行为或业务组合不足时，应把精确问题返回相应事实拥有者；事实修订后只重新形成受影响投影。

推荐输入是业务定义、领域地图、独立 Domain 文档和业务组合，但不要求它们必须先被宣布为全部完成。使用草稿时记录来源成熟度、假设、受影响设计和可能返工范围。

## 尚待共同设计

- Pre-Coding 的专业角色及独立派发粒度；
- 每类投影的上下文清单和读取范围；
- 权威产出及 Obsidian 模板；
- 产出之间的链接和刷新规则；
- 用户确认与 Coding 使用合同。

协议完成前，主控不得使用旧版系统设计 Agent 冒充新版角色。缺少的是本能力的专业协议，不表示 Coding 被禁止；用户仍可按现有代码或部分事实工作，并明确相应假设与风险。
