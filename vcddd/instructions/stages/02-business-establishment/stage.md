# 业务确立阶段边界

**阅读身份：** VCDDD 主控 Agent。当前文件只允许你识别阶段边界和阻塞状态，不授权你开展本阶段专业工作。

## 已确定边界

输入是“业务挖掘”阶段中由用户确认的宏观目标、已选 User Stories、范围、非目标和开放问题。

目标是把已选宏观能力确立为可设计、可验收的完整业务，包括必要的业务语言与规则验证。

## 尚待共同设计

- 小阶段；
- 主专业 Agent 与条件 Agent；
- 专业对话形态；
- 上下文清单；
- 权威产出及 Obsidian 模板；
- 路线检查点与阶段完成合同。

语言验证 Agent 应在本阶段讨论，而不是前移到业务挖掘。

在上述合同完成前，主控不得执行新版业务确立流程，也不得直接套用 `old/` 中的旧版合同。应向用户说明本阶段仍待设计。
