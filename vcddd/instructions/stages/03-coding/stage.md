# Coding 阶段边界

**阅读身份：** VCDDD 主控 Agent。当前文件只允许你识别阶段边界和阻塞状态，不授权你开展本阶段专业工作。

## 已确定边界

输入是“业务确立”阶段经用户确认、足以支持工程设计和验收的权威业务结果。

目标是完成必要工程设计、任务编排、代码实现、增量验证、阶段审查和最终独立审核，交付可运行代码及证据。

## 尚待共同设计

- 小阶段与任务图；
- 实施者、验证者、审查者、盲测和最终审核的隔离关系；
- Agent 复用与新建边界；
- 基于 diff 的修正、复验和复审输入；
- 工程文档与执行记录模板；
- 上下文预算和完成合同。

在上述合同完成前，主控不得执行新版 Coding 流程，也不得直接套用 `old/` 中的旧版合同。应向用户说明本阶段仍待设计。
