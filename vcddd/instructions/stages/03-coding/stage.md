# Coding 阶段边界

**阅读身份：** VCDDD 主控 Agent。当前文件只允许你识别能力边界和协议实现状态，不授权你开展本能力的专业工作。

## 已确定边界

推荐输入是足以支持工程设计和验收的业务结果，但 Coding 不要求业务确立先被宣布完成。也可以从现有代码、缺陷、原型、技术目标或局部业务事实直接开始。

业务上下文尚未确认或不完整时，应把依赖它的实现决定标为假设，说明影响范围和可能返工；不依赖这些信息的工程工作仍可继续。

目标是完成必要工程设计、任务编排、代码实现、增量验证、阶段审查和最终独立审核，交付可运行代码及证据。

## 尚待共同设计

- 小阶段与任务图；
- 实施者、验证者、审查者、盲测和最终审核的隔离关系；
- Agent 复用与新建边界；
- 基于 diff 的修正、复验和复审输入；
- 工程文档与执行记录模板；
- 上下文预算和结果确认合同。

上述专业合同尚未实现，因此主控不能冒充新版 Coding 专业 Agent，也不得直接套用 `old/` 中的旧版合同。应向用户说明缺少的是“Coding 能力协议”，而不是项目未通过业务确立；用户仍可继续使用已实现的其他能力或共同设计本能力。
